# DC Notifier — барномаи Android барои автопардохт

Ин барнома notification-ҳои воридоти пул (Зачисление)-ро аз DC Next мехонад
ва матни хомашонро ба гурӯҳи Telegram (тавассути боти notifier) мефиристад.
Боти асосӣ дар сервер онро парс карда, фармоишро худкор тасдиқ мекунад.

## Чӣ тавр APK-ро месозем (бе компютер, бе Android Studio)

1. Дар GitHub (github.com) ҳисоб созед (агар надошта бошед — ройгон).
2. Репозиторийи НАВ созед (масалан `dc-notifier`), метавонад Private бошад.
3. Ҳамаи файлҳои ин папкаро ба он repo бор кунед (Upload files). МУҲИМ:
   сохтори папкаҳоро нигоҳ доред (масалан `app/src/main/...`). Осонтарин
   роҳ: ҳамин папкаро ZIP карда, дар компютери ҳамсоя/дӯст unzip ва
   upload кунед, Ё тавассути GitHub веб-интерфейс папка ба папка созед.
4. Баъд аз бор шудан, ба таби **Actions** равед — GitHub худкор APK-ро
   месозад (2-5 дақиқа).
5. Вақте сабз шуд, ба дохили run зер кунед → поён **Artifacts** →
   **DCNotifier-APK**-ро зеркашӣ кунед. Дар дохилаш `app-debug.apk` ҳаст.
6. `app-debug.apk`-ро ба телефони алоҳида гузаронед ва насб кунед
   (Танзимот → иҷозати насб аз манбаъҳои носинос лозим мешавад).

## Танзим дар телефон (як маротиба)

1. Барномаро кушоед.
2. **Токени боти notifier**-ро ворид кунед (аз @BotFather гирифтед).
3. **Chat ID-и гурӯҳ**-ро ворид кунед (бо минус, масалан `-1001234567890`).
4. «💾 Сабт кардан»-ро пахш кунед.
5. «📨 Санҷиш»-ро пахш кунед — дар гурӯҳ бояд паёми тест ояд.
6. «🔔 Иҷозати хондани notification»-ро пахш кунед — дар рӯйхат
   **DC Notifier**-ро ёфта, фаъол кунед.
7. «🔋 Хомӯш кардани сарфаи батарея»-ро пахш кунед ва тасдиқ кунед.
8. Телефонро доим ба барқ пайваст нигоҳ доред ва DC Next-ро насбшуда
   бо notification-ҳои фаъол.

## Санҷиши охирин

Аз ягон корт ба корти DC-и худ маблағи хурд (масалан 1 сомонӣ) фиристед.
Дар гурӯҳи Telegram бояд паёме монанди ин ояд:

```
DCNOTIF [tj.dc.next]
Зачисление средств
Zachislenie Summa 1.00 TJS ... Kod 177xxxxxxxx ...
```

Агар омад — ҳама кор мекунад! Боти асосӣ ин паёмро худаш мехонад.

## Санҷиши даврии иловагӣ (ихтиёрӣ)

Ин функсия ба таври **иловагӣ** (на ивазкунанда) кор мекунад — ҳатто агар
онро насб накунед, механизми асосии боло (notification) кор мекунад.

Он ҳар 20-40 дақ (рӯзона) ё 2-3 соат (шабона, вақти комилан тасодуфӣ, бе
такрор) худкор барномаи DC City-ро дар ҳамин телефон мекушояд, саҳифаи
"Таърих → Амалиётҳо"-ро мехонад. **Ҳар санҷиш як хабар ба гурӯҳи
Telegram мефиристад** (агар амалиёти нав набошад ҳам — "амалиёти нав
ёфт нашуд", то маълум шавад, ки санҷиш зинда аст). Агар амалиёти нав
ёфт шавад, бо тамғаи:
- ✅ Вобаста ба фармоиши №X (агар коменти `card_XXX` дошта бошад)
- ❓ Аз Алиф (бе рамз — санҷиши маблағ лозим аст аз тарафи сервер)
- ⚠️ Вобастагӣ ба бот надорад (масалан WOOPPAY ё интиқоли шахсӣ)

**Ин тамғагузорӣ танҳо аз рӯи ШАКЛИ матн аст (эҳтимолӣ)** — сервери
асосӣ метавонад минбаъд аз рӯи базаи фармоишҳо санҷиши дақиқтар кунад.

### Танзим

1. Дар барнома, майдони **"PIN-и 4-рақамаи ҳисоби DC"**-ро пур кунед ва
   "🔐 PIN-ро сабт кардан"-ро пахш кунед. PIN танҳо дар ҳамин телефон, бо
   рамзгузории Android (Keystore) нигоҳ дошта мешавад — ба сервер
   ҳаргиз фиристода намешавад.
2. "♿ Иҷозати Accessibility"-ро пахш кунед → дар рӯйхат **DC Notifier**-ро
   ёфта фаъол кунед (Android аз шумо огоҳии стандартӣ мепурсад — тасдиқ
   кунед).
3. Ҳамин! Санҷиши аввал дар давоми якчанд дақиқа худкор сар мешавад.

### Хатари эҳтимолӣ ва маҳдудият

- Агар барномаи DC тарҳи экрани худро (масалан матни "Рамзи дастрасиро
  ворид кунед" ё номи табҳо) тағйир диҳад, ин механизм то санҷиши нав
  кор намекунад — механизми асосии notification бошад ҳамчунон фаъол
  мемонад.
- Кушодани худкори барнома дар ҳамин телефон (на аз сервери дур) хатари
  "блок шудан аз ДС"-ро назар ба воридшавии сервери дур хеле кам
  мекунад, вале пурра рафъ намекунад — тавсия мешавад аввал якчанд рӯз
  назорат кунед (огоҳиномаҳо/талаби тасдиқи иловагӣ аз ДС наомадаанд ё
  не), пеш аз он ки пурра ба он такя кунед.
